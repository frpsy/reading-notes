# 책갈피 디자인 v7 — 덜어내기 (2026-11-18)

v6에서 맞춘 글자·여백 기준은 그대로 두고, 같은 정보를 두 번 보여 주거나 층이 많아 길어지던 곳을 줄였다. 규칙은 `style.css` 끝의 "디자인 v7" 블록에 모았다.

- **책 상세 첫 화면:** 진척(%·조각 막대)과 이어 읽기를 한 판(`.panel.next`)으로 묶고, '위치·읽음 표시' 버튼을 다음 챕터 제목과 한 줄에 둔다(340px 이하에서만 두 줄). 챕터 목록이 휴대폰 첫 화면에서 약 100px 일찍 시작한다. 완독한 책은 전과 같이 완독 판 + 진척.
- **상태 칩 중복 제거:** 책 머리는 '읽는 중' 대신 쉬는 중일 때만 '잠시 쉬는 중' 하나를 보인다. 서재 카드는 묶음 제목·필터가 상태를 알려 주므로 검색 결과처럼 섞인 목록에서만 상태 칩을 보이고, '잠시 쉬는 중'은 메타 줄 끝에 글자로 붙인다.
- **서재 카드 6층 → 4층:** 큰 %를 진행 막대 오른쪽으로 옮겼다. '이어서 읽기' 카드에 나온 책은 아래 카드에서 '다음' 줄을 반복하지 않는다. 900px 이상에서는 카드를 두 칸으로 놓는다.
- **챕터 ⋯:** 마우스 화면에서는 줄에 올리거나 초점이 갈 때만 보이고, 휴대폰에서는 아이콘을 18px로 줄였다(터치 영역 44px 유지).
- **독서 메모:** 평점 줄과 메모를 구분선으로 나누고, 꺼진 별을 옅게 했다. 메모가 비어 있으면 '접기' 없이 입력란을 바로 보인다(닫아 둔 상태가 복원되면 '메모 쓰기'로 다시 연다).

검증: 단위 93개, 스모크 57단계, design Chromium·WebKit, perf 통과. 스모크·design 테스트는 의도한 변경(목록 카드 칩 제거, 빈 메모 '접기' 숨김)에 맞게 고쳤다. 실제 iPhone Safari·홈 화면 앱은 미확인.
