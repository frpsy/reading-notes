# 책갈피 디자인 v6 — 가독성 기준 (2026-11-18)

색·데이터 구조는 그대로 두고 글자 크기 단계, 자간, 줄바꿈, 여백, 정렬을 한 기준으로 맞췄다. 규칙은 `style.css` 끝의 "가독성 기준 v6" 블록에 모았다.

- **글자 단계:** 페이지 제목 26px(PC 768px 이상 28px) · 책 제목 24px(PC 26px) · 섹션 16px · 카드 제목 17px · 보조 14px · 메타 13px · 칩 12px. 전에는 페이지 제목이 서재 24px, 다른 화면 28px, 책 상세 23px로 달랐고 휴대폰 제목이 PC보다 컸다.
- **넓은 화면 역전 해소:** 휴대폰에만 최소 크기를 올려 두어 PC에서 칩 11px, 메타 12px, 챕터 제목 16px로 오히려 작아지던 27곳을 431px 이상에도 같은 크기로 맞췄다.
- **줄바꿈:** 본문 전체에 `word-break: keep-all`로 "보관합/니다"처럼 단어 중간에서 끊기지 않게 하고, 문단은 `text-wrap: pretty`로 마지막 줄 외톨이 글자를 줄였다.
- **자간:** 큰 제목의 −0.045em을 −0.02em으로, 카드 제목 −0.025em을 −0.01em으로 완화했다.
- **여백:** 제목과 첫 내용 사이 20px, '← 뒤로'와 제목 사이 10px(PC 12px)로 모든 화면을 통일했다. 책 머리는 위쪽 정렬로 바꿔 저자 줄 길이에 따라 제목이 흔들리지 않는다.
- **정렬:** 설정 화면의 섹션 이름·항목·안내·버튼 왼쪽 시작점을 하나로(휴대폰 12px, PC 14px 안쪽).
- **위계:** 기록 관리의 빈 상태 문구가 설명보다 컸던 것을 14px로. 서재 필터 탭도 다크 모드에서 선택 테두리를 보인다.

검증: `e2e/design.mjs`에 불변식 추가 — 페이지 제목 크기(26/28px)·제목 아래 20px·제목 자간 −0.025em 이상, 설정 왼쪽 정렬, 넓은 화면 글자가 390px보다 작아지지 않음. 단위 93개, 스모크 57단계, design Chromium·WebKit 통과. 실제 iPhone Safari·홈 화면 앱은 미확인.
