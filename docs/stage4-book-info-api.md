## 판단

- 이 앱의 핵심인 **목차**를 공식적으로 주는 곳은 확인한 범위에서 알라딘뿐입니다. 그마저 책마다 제공 여부가 다를 수 있습니다(미확인).
- 키를 숨기려면 서버(예: Cloud Functions)가 필요합니다. 그러면 유료 요금제나 외부 계정 연결이 필요할 수 있어, 계획서상 승인이 필요한 일입니다.
- 지금의 "공식 서점 목차 확인 후 `catalog/`에 추가" 방식이 정확도와 유지보수 면에서 낫다고 판단해, 도입하지 않습니다.
- 다시 검토한다면: 알라딘 `Toc`의 한국어 목차 품질을 표본 20권으로 확인 → 키 보호 방식 결정(승인) → 붙여넣기 화면에 "불러오기" 버튼으로만 추가(자동 저장하지 않고 미리보기 후 사용자가 확정).
