# 5단계 품질 검증 (2026-10-31)

실행 환경: Linux 컨테이너, Node 22, Chromium(Playwright 1.63), Firestore 에뮬레이터 v1.22.0.
e2e는 테스트 전용 Firebase 대역을 쓰므로 **실제 Firestore·실제 구글 로그인 검증이 아닙니다.**

## 자동 테스트 결과

| 종류 | 명령 | 결과 |
|---|---|---|
| 단위 | `npm test` | 48개 통과 |
| 보안 규칙(에뮬레이터) | `npm run test:rules` | 8개 통과(uid 조건을 빼면 실패함을 확인) |
| 브라우저(Chromium, 데스크톱·390px) | `npm run e2e` | 29단계 통과 |
