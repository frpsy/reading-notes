## 보호한 동작

챕터 줄 체크·취소, 부분 렌더링, 스크롤 복원, 메모 자동 저장, 되돌리기·휴지통, 백업, 검색·필터, 날짜·평점은 유지한다. Firestore 스키마·규칙·저장/병합 로직은 변경하지 않는다. 배포용 모듈 버전만 함께 올린다.

## 검증과 증거

- `npm test`: 순수 로직·데이터 보호·서비스 워커 검사 52개.
- 기존 `e2e/smoke.mjs`: 로그인·체크·메모·새로고침·실패 복구·다중 탭·삭제·복원·백업 회귀.
- `e2e/design.mjs`: Chromium, WebKit / 320·375·390·430·768·1280px / 라이트·다크 / 서재·상세·입력·기록 관리. 긴 영문 제목·200% 텍스트·44px 터치·키보드 Space 체크·움직임 줄이기 검사.
- 기준 버전과 수정 버전을 같은 데이터·폭·테마로 캡처. GitHub Actions `design-screenshots/before`, `after` 아티팩트.
- 기존 `e2e/perf.mjs`: 100권·5,000챕터·1,000메모, 별도 3,000챕터 책의 응답 성능.
- Firestore 에뮬레이터에서 규칙 검사. 운영 프로젝트 데이터에는 접속하지 않는다.

## 남은 검증 한계

WebKit은 실제 iPhone Safari·홈 화면 설치 앱을 완전히 대체하지 않는다. 실제 iPhone의 소프트 키보드, 주소창 접힘, Safe Area 가로 모드, 설치·인증 복귀는 실기기 확인이 필요하다. 테스트 대역에서 통과한 저장 검증을 실제 운영 계정의 네트워크 동기화 검증으로 표현하지 않는다.
