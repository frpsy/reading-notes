## 3. 이번 PR에서 한 속도 개선

1. 글꼴 CSS 를 `@import` 에서 `index.html` 의 비차단 `<link>` 로 옮기고 `preconnect` 를 추가. 글꼴 때문에 첫 표시가 막히지 않습니다. 글꼴은 `display=swap` 이라 늦게 도착하면 글자 모양이 바뀝니다(실기기 시각 영향 미확인).
2. 서비스 워커: 주소에 `?v=번호` 가 붙은 화면 파일은 `no-cache` 재확인을 생략. 배포마다 주소가 바뀌므로 새 배포는 그대로 반영됩니다. `index.html`·`catalog/index.json` 등 주소가 같은 파일은 계속 서버에 확인합니다.
   - 측정(로컬 서버, ETag + `max-age=600` 헤더, HTTP 캐시 켠 상태, 재방문 로드): 서버 요청 32건(전부 304 재확인) → 10건.
   - 주의: `?v=` 를 올리지 않고 JS·CSS 를 고치면 최대 10분간(캐시 유효시간) 옛 파일이 보일 수 있습니다. CLAUDE.md 의 "바꾸면 `?v=` 를 올린다" 규칙이 더 중요해집니다.
3. 시도 후 되돌림: 서재 검색의 다시 그리기를 한 프레임에 한 번으로 합치는 변경. 기존 e2e 가 입력 직후 목록이 바로 바뀌는 것을 전제로 해 실패했고, 이득이 빠른 연속 입력에만 있어 되돌렸습니다. 대신 아래 R3 로 비용 자체를 줄입니다.
4. `e2e/perf.mjs` 에 "검색 4글자 연속 입력" 항목 추가(변경 전 기준: 다시 그림 4회, 142~204ms).
