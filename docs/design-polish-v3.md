# 책갈피 추가 개선

기준 b781bc1. 기존 데이터 구조와 저장 로직을 유지한다.

- 서재 검색: 메모 검색에도 현재 상태 필터를 동일하게 적용한다. 결과 수를 알리고, 빈 결과에서 전체 서재로 복귀하고 검색 입력으로 포커스를 돌린다.
- 독서 흐름: 검색·필터 사용 중에는 관련 없는 독서 알림을 숨긴다. 알림 문구는 독서를 재촉하지 않는 표현으로 정리한다.
- 책 추가: 짧은 목차 안내와 접히는 상세 설명으로 나눈다. 제목·목차 오류는 해당 입력란에 포커스를 보내고 오류를 연결한다. 다시 입력하면 이전 오류 표시를 해제한다.
- 상세: 진도 막대에 화면 읽기 도구용 현재 값과 전체 값을 제공한다. 체크 시 기존 부분 갱신으로 함께 반영한다.
- 테마: 브라우저·설치 앱의 theme-color를 화면 배경색과 맞춘다. 자동 테마에서는 운영체제 테마 변경에도 갱신한다.
- 검증: 기존 52개 단위·저장 보호 검사, 스모크 회귀, Chromium/WebKit 6개 폭·양쪽 테마 검사에 필터 검색·빈 결과 복귀·입력 오류 포커스·진도 접근성·테마 자동 전환 검사를 추가한다. b781bc1과 동일 조건 캡처를 CI 아티팩트로 보관한다.

실제 iPhone의 키보드·홈 화면 설치 동작은 브라우저 엔진 검사와 별도로 실기기 검증이 필요하다.
