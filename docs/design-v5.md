# 책갈피 디자인 v5 (2026-11-18)

v4 위에서 보조 화면을 정돈했다. 색·글꼴·데이터 구조는 그대로다.

- **책 찾기:** 카드에 v4 책 모양 표지를 쓰고, 담기 전에 분량을 가늠하도록 `N챕터 · N쪽`을 보여 준다. 화면을 가득 채우던 '서재에 담기' 버튼은 카드 오른쪽의 '담기' 버튼(44px 이상)으로 줄였고, 화면 읽기 도구에는 '○○ 서재에 담기'로 읽힌다.
- **독서 활동 히트맵:** 왼쪽에 요일(월·수·금), 위에 새 달이 시작되는 주의 'N월'을 표시한다(`core.heatmapMonths`). 오늘 칸은 테두리로 구분한다. 연속 기록이 없으면 '0일 연속' 대신 '연속 기록 없음'이라고 쓴다. 라벨은 12px로 iPhone 최소 글자 기준을 지킨다.
- **연간 기록:** 이번 해를 볼 때 이번 달 막대 라벨을 강조색으로 표시한다. 완독한 책 표지는 다른 화면과 같은 책 모양 표지를 쓴다.

검증: 단위 테스트 81개, `e2e/smoke.mjs` 56개, `e2e/design.mjs` Chromium·WebKit(6개 폭, 라이트·다크, 200% 글자, 터치 영역) 통과. 실제 iPhone Safari·홈 화면 앱은 미확인.
