# 책갈피 디자인 v4 (2026-11-17)

기존 색·글꼴·레이아웃·저장 구조는 그대로 두고, 앱 이름인 '책갈피'를 화면 언어로 삼았다. 챕터 체크 줄의 크기와 동작은 바꾸지 않았다.

- **책 모양 표지:** 표지(`.cover`)에 책등 그림자와 오른쪽 책장 단면을 넣어 책처럼 보이게 했다. 크기·위치는 그대로다.
- **책갈피 리본:** 읽는 중인 책의 표지에만 리본(`.cover.marked`, `--ribbon`)을 꽂는다. 서재 목록, 이어서 읽기, 책 상세 머리에서 같은 표시다. 독서 예정·완독한 책에는 없다.
- **챕터 칸 진도:** 책 상세의 진도 막대를 읽을 단위(챕터)마다 한 칸으로 나눴다(`.bar.seg`). 읽은 칸은 채우고 다음 챕터는 테두리로 표시한다. 챕터가 60개를 넘으면 기존 막대를 쓴다. `role="progressbar"`와 값은 그대로다(`core.progressSegments`).
- **최근 7일 리듬:** 서재 '이어서 읽기' 카드에 최근 7일 중 챕터를 읽은 날을 점 일곱 개로 보여 준다. 오늘 점은 고리로 구분한다. 읽은 날이 없으면 표시하지 않고, 재촉하는 문구는 넣지 않는다(`core.recentDays`).
- **접근성:** 장식 요소는 `aria-hidden`이고 같은 정보는 글로도 있다. 강제 색상 모드에서는 칸과 점에 테두리를 둔다. 동작 줄이기 설정에서는 칸 전환 효과를 끈다.

검증: 단위 테스트 78개, `e2e/smoke.mjs` 56개, `e2e/design.mjs`(Chromium·WebKit, 6개 폭, 라이트·다크) 통과. 실제 iPhone Safari·홈 화면 앱은 미확인.
