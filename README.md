# 책갈피

책의 공식 목차를 넣고 챕터를 읽을 때마다 체크하며 독서 진도를 기록하는 웹 앱입니다.

## 기능

- 준비된 책 담기(`catalog/`)
- 챕터 체크 시 오늘 날짜 기록(날짜 수정 가능), 묶음 항목 일괄 체크, 챕터별 메모
- 시작일·종료일(전부 읽으면 자동)·목표 완독일, 진척 %, 분량(쪽수) 기준 %, 읽는 속도, 예상 완독일, 누적 그래프
- 오늘 아직 읽지 않았으면 서재 상단에 이어 읽기 안내(연속 기록이 끊길 때·며칠 쉴 때)
- 서재 필터(읽는 중·읽을 예정·완독)와 제목·저자 검색, 7일 넘게 기록 없음 표시, 평점·독서 메모
- 모바일 메모: 짧은 메모는 눌러서 바로 수정, 입력란이 글에 맞게 늘어나고 글자 수·저장 상태·하단 완료 버튼 제공
- 책별 챕터 메모 모아보기, 연간 기록(완독한 책·월별 완료 챕터·읽은 날)
- 책 추가: 제목과 목차를 직접 붙여 넣거나, Claude에게 책 이름을 말해 `catalog/` 에 올라온 준비된 책을 서재에 담기
- 오프라인 사용: 한 번 열어 둔 기기에서는 연결 없이도 앱이 열리고, 체크한 기록은 기기에 보관했다가 연결되면 자동 저장합니다
- 백업 내려받기·가져오기는 없습니다

## 데이터와 로그인

구글 로그인(허용 계정만)으로 Firestore `readingUsers/{uid}/books/{id}` 에 저장하며, 어느 기기에서나 같은 기록을 봅니다. 로그인 없이 사용하는 체험 모드는 제공하지 않습니다.

입력·삭제는 로그인 계정별 전송 대기열에 즉시 보관한 뒤 서버에 저장합니다. 오프라인이나 저장 실패 후 새로고침해도 같은 계정으로 로그인하면 대기 기록을 복구하며, 연결 복구 또는 상단의 다시 시도 버튼으로 재전송합니다. 저장 공간 부족은 화면에 안내합니다. 다른 기기에서 바꾼 챕터·메모는 트랜잭션으로 병합하며, 같은 항목을 수정하면 나중에 전송한 값이 반영됩니다. 서로 다른 목차 구조로 동시에 수정하거나 다른 기기에서 삭제한 책을 수정하면 덮어쓰지 않고 오류와 대기 기록을 보존합니다.

### 한 번만 하는 설정

1. Firebase 콘솔(프로젝트 `chaekgalpi-reading`, 책갈피 전용) > Firestore > 규칙에 `firestore.rules.reading` 의 내용을 게시합니다.
2. Authentication > 로그인 방법에서 Google 사용, 승인된 도메인에 `frpsy.github.io` 가 있는지 확인합니다.
3. 저장소 Settings > Pages > Source 를 **GitHub Actions** 로 바꿉니다. main 에 반영되면 테스트 후 자동 배포됩니다.

배포 주소: `https://frpsy.github.io/reading-notes/`

## 개발

```bash
npm test      # 단위 테스트 (Node 20+)
npm start     # http://localhost:8080
```

Firebase 설정이 없으면 로그인 설정 오류를 표시합니다. `npm run e2e`는 테스트 서버에서만 Firebase 대역을 연결해 로그인·저장 복구·여러 탭의 변경 병합을 검증합니다. 테스트 대역은 배포에 포함되지 않습니다.
